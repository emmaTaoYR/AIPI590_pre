01 · Product value

From knowing the deadline
to knowing the next step.

Our proposed advantage is coordinating several returns over time.

Decide

What needs
attention first?

Prioritize intended returns by deadline and refund at risk.

Less decision friction

The user still chooses Keep, Return or Not sure.

Act

What can I
do together?

Help start each return, confirm its method and group compatible drop-offs.

Less administrative work

One action plan and one place for return materials.

Follow through

What is
still unfinished?

Keep item status, reminders and retailer refund updates connected.

Less repeated input

An ongoing workflow across orders and retailers.

09 · Decisions + reminders

Help me move forward.
At the right moment.

Before the decision

“I’m not sure yet.”

Keep the item in a deciding state and set a decision reminder.

KeepReturnNot sure
The user decides.

AI does not choose what to keep.

Before the deadline

“What needs doing?”

Remind the user to decide, initiate or drop off according to the item’s state.

Adjust timing and intensity.

Respect user settings and the remaining return window.

After a missed window

“What can I do now?”

Clearly mark the missed deadline and offer relevant resale links.

A fallback, outside the core.

No resale marketplace is required for the MVP.

One reminder, one clear next action.Decision → initiation → drop-off → refund follow-up.
